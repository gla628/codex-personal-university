# 教室配置说明 / Classroom context

本参考用于配置当前用户的课程教室，不附带任何已有账号、教室或表格的授权。

This reference configures classrooms for the current learner. It carries no permission for any existing account, conversation, or workbook.

创建或复用前核实 / Resolve before creating or reusing:

- 课程唯一编号、名称、已选身份 / Unique course ID, name, and selection status.
- 完整课程规划与可访问材料 / Full course plan and accessible materials.
- 真实最新进度与暂停位置 / Actual latest progress and resume point.
- 用户指定的侧栏分区；没有指定时先保持现状 / Requested sidebar section; preserve the current organization when none is specified.
- 实际课程总目录和教室链接字段 / Real course catalog and classroom-link field.
- 用户是否已授权创建、打开、消息发送及相应记录写入 / User authorization for creation, navigation, messaging, and record updates.
- 模型、项目和主机要求；遵循当前用户选择，不套用示例作者设置 / Model, project, and host preferences; follow the current user's choices.

独立教室应从第一课到结课复用同一真实对话。没有创建工具时，提供完整交接文本供用户手动新建；没有表格连接时，保留可携带的课程与进度摘要。不要编造对话 ID、已创建状态或已登记结果。

Reuse one real conversation from the first lesson through course completion. If creation tools are unavailable, provide a complete handoff for manual setup. If records are disconnected, provide a portable course and progress summary. Never invent a conversation ID or claim an unperformed action succeeded.

学习进度由课程教室在实际事件中记录；总规划对话按需读取已有记录。无需为普通进度开启后台轮询、跨对话广播或定时任务。

Classrooms record progress during actual learning events. The planning conversation reads those records when needed; ordinary progress does not require background polling, broadcasts, or scheduled jobs.
