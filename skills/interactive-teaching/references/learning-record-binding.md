# 学习记录绑定说明 / Learning record binding

本文件是配置说明，没有预设的表格地址或写入授权。对当前学习者，先从其提供的配置或当前对话核实以下内容；已知信息不重复询问。

This reference is configuration guidance. It contains no workbook address or permission to update records. Resolve the following from the current learner's supplied context or conversation.

| 所需信息 / Required context | 用途 / Purpose |
| --- | --- |
| 实际工作簿或本地记录位置 / Actual workbook or local record | 确认读写对象 / Identify the destination |
| 课程总目录、课程表、课时明细的实际名称 / Actual catalog, timetable and lesson records | 沿用现有结构 / Preserve the existing structure |
| 课程编号与课次字段 / Course and lesson identifiers | 定位唯一课次 / Identify the correct lesson |
| 状态、实际日期、笔记字段与允许状态值 / Status, real dates, notes and permitted values | 表达真实进度 / Record actual progress |
| 用户时区与真实学习日期 / User time zone and actual study date | 避免虚构日期 / Avoid invented dates |
| 明确授权的课程、字段和动作 / Authorized courses, fields and actions | 约束写入范围 / Scope updates |
| 用户已有的手工安排与备注 / Existing manual plans and notes | 保留用户工作 / Preserve user work |

可在已获授权范围内随实际开课、暂停、结束或用户明确报告更新记录。预先完成备课不能标为已完成；“学完”与独立掌握的证据分开记录。暂停默认保留未完成状态，在笔记中记录起点；若用户表格已有暂停状态则按其规则使用。

Within the actual authorization, update records when teaching starts, pauses, ends, or when the user explicitly reports progress. Preparing materials is not lesson completion. Keep completion separate from mastery evidence. Preserve a resume point when pausing.

写前按当前表头和唯一课程课次定位，写后回读同一条记录。失败时保留真实进度与待同步内容，不声称已同步。没有外部写入授权时使用对话摘要；用户授权保存本地记录时可以写入其指定目录。

Resolve the current headers and unique lesson before writing, then read back the same record. If synchronization fails, retain the actual progress and pending updates without claiming success. Without external write permission, provide a chat summary or a local note in a location the user has authorized.

本技能没有固定每日节数、时区、Sheet 数量、行号或列号。不要从示例继承任何人的账户、权限或学习状态。

No daily quota, time zone, sheet count, row number, or column number is fixed here. Do not inherit another learner's accounts, permissions, or progress from an example.
